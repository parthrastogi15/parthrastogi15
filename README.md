### 👋 About me

I'm a C++ engineer who builds **low-latency trading infrastructure** for a proprietary trading firm — order management systems, market data handlers and exchange connectivity across Indian, Korean, US and crypto venues.

- ⚡ Hot paths tuned to **sub-microsecond** latency; kernel-bypass TCP/UDP on **ExaNIC / FPGA** (TCP send ~400ns → ~100ns p99)
- 📈 Multi-venue **OMS**, **market data** feed handlers, normalisation and smart routing
- 🛠️ Colo bring-up: bare-metal provisioning, kernel/NIC tuning, profiling and jitter hunting

### 💼 What I work on

| Service | Typical work |
| --- | --- |
| **C++ performance tuning** | Profiling (perf, VTune, flamegraphs), cache/allocation fixes, lock-free queues, p99 jitter reduction |
| **Trading systems** | Exchange connectivity (FIX / binary / WebSocket), feed handlers, order books, OMS, backtest/sim engines |
| **Low-latency networking** | Kernel-bypass (ExaNIC, Solarflare/OpenOnload), custom TCP/UDP, packet capture & replay |
| **Linux systems** | Multithreading, CPU pinning/isolation, NIC & kernel tuning, drivers, CI/CD for C++ |
| **Code review & modernisation** | Legacy C++ → C++17/20, build systems (CMake), test & benchmark harnesses |
